# Bloomie — gestengesteuerte Schreibtischlampe an einem Roboterarm (HRI-Teamprojekt)

**Bloomie ist eine Schreibtischlampe, die auf einem Roboterarm sitzt und sich berührungslos über Kamera-Gesten steuern lässt** — entstanden als Teamprojekt im Kurs Human-Robot Interaction (LMU München).

| | |
|---|---|
| Kontext | Kurs Human-Robot Interaction (HRI), LMU München |
| Rolle | Lichtsystem: verstellbarer Lichtkegel über eine bewegliche Linse + LED-Hardware |
| Projektbericht | [Leoniexck/HRI-Bloomie-Report](https://github.com/Leoniexck/HRI-Bloomie-Report) |

## Das Projekt

Statt Schalter oder App: Die Lampe erkennt Handgesten über eine Kamera und reagiert darauf — der Roboterarm bewegt und richtet das Licht aus. Ein Human-Robot-Interaction-Experiment darüber, wie sich ein Alltagsobjekt anfühlt, wenn es sich wie ein Gegenüber verhält statt wie ein Gerät.

## Mein Beitrag: das Lichtsystem

- **Verstellbarer Lichtkegel nach dem Fokus-Prinzip einer Kameralinse:** Vor der LED sitzt eine Linse, die der Roboter näher heran- oder weiter wegfahren kann. Über diesen Abstand verschiebt sich der Lichtkegel stufenlos von eng gebündeltem Spot bis zu breitem Flutlicht — die Optik habe ich konzipiert, gebaut und eingestellt.
- **LED-Hardware:** Auswahl und Einbau der LED-Beleuchtung samt Ansteuerung im Lampenkopf.

## Technologien

Roboterarm · Kamera-basierte Gestensteuerung · LED-Hardware · Optik (bewegliche Linse für den variablen Lichtkegel) · Hardware-Prototyping
